# Domain Docs

## 文档布局

采用 single-context：
- 根目录 CONTEXT.md：业务术语和领域说明。
- docs/adr/：架构决策记录。

## 阅读规则

探索代码前，读取 CONTEXT.md 和与当前任务相关的 ADR。
若以后出现 CONTEXT-MAP.md，则按其中指引读取相关领域文档。

文档不存在时直接继续，不提前要求创建。
领域术语或决策明确后，由 domain-modeling 技能按需建立文档。

## 术语与决策

任务标题、方案、测试名称等应使用 CONTEXT.md 中约定的术语。
缺少术语时先检查是否引入了不必要的新叫法，必要时记录待补充项。

方案与已有 ADR 冲突时，明确指出冲突及重新讨论的理由，
不得静默覆盖已有决策。
